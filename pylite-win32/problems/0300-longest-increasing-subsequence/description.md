# 300. 最长递增子序列

## 题目描述

给定一个长度为 `n` 的整数序列，请求出其中最长严格递增子序列的长度。

子序列可以通过删除原序列中的若干元素得到，但剩余元素的相对顺序不能改变。“严格递增”表示后一项必须大于前一项，相等的数字不能同时延长该子序列。

## 输入格式

第一行包含一个整数 `n`，表示序列长度。

第二行包含 `n` 个整数 `a1, a2, ..., an`，表示给定序列。

## 输出格式

输出一个整数，表示最长严格递增子序列的长度。

## 样例 1

```text
输入：
8
10 9 2 5 3 7 101 18

输出：
4
```

一种长度为 `4` 的严格递增子序列是 `2, 3, 7, 101`。

## 样例 2

```text
输入：
6
0 1 0 3 2 3

输出：
4
```

## 数据范围

- `1 <= n <= 2500`
- `-10000 <= ai <= 10000`
